# my-portfolio

Personal developer portfolio application designed to showcase projects, skills, and technical background. Built with modern web tools for high performance and smooth user experience.

---

### Features

- **Interactive UI**: Clean, responsive layout showcasing projects and technical stack.
- **Dynamic Profile Component**: Introductory section with tailored branding and custom styles.
- **Icon Integration**: Built with `react-icons` for intuitive visuals.
- **Fast Build System**: Powered by Vite for optimal bundle performance.

---

### Tech Stack

- **Framework / Library**: React
- **Language**: TypeScript
- **Build Tool**: Vite (`vite.config.ts`)
- **Icons**: React Icons
- **Deployment**: Vercel
